# Черновое проектирование v2 — восстановлено и проверено

## Результат восстановления

В более раннем описании упоминался пакет v2, однако он не был сохранён. Удалённая ветка `feature/production-drafting-v2` содержала только рабочий процесс импорта, а не исходные изменения v2. Данный PR восстанавливает реальную функциональность из ветки main в коммите `b64c9627c25899b0676ec8890506cbe39c22cf86`. Он не претендует на восстановление отсутствующих данных и не опирается на ранее заявленные 113 проверок.

## Новые рабочие пути

`Drafting` — новая вкладка ленты. Каждая из перечисленных ниже команд также доступна через поиск по Ctrl+K.

| Команды | Реализация |
|---|---|
| BLOCK, BINSERT, BEDIT, BCLOSE, ATTEDIT | Общие определения, преобразованные ссылки, вложенные блоки, отдельный редактор определений, атрибуты для каждого экземпляра, разъединение/отмена; собственная持久ность. Буфер обмена переназначает определения и зависимости стилей/слоёв. |
| DIMLINEAR, DIMRADIUS, DIMDIAMETER, DIMANGULAR, DIMORDINATE, DIMSTYLE | Реальная геометрия и текст измерений; общие параметры стиля размеров. Линейные размеры могут ссылаться на выбранные концы отрезков и обновляться при редактировании. Отсутствующие источники помечаются как повреждённые, а не молча отбрасываются. |
| HATCHISLANDS | Штриховка/сплошная заливка с островами по принципу чёт-нечёт, включая вложенные острова. Выбранные границы связаны и перегенерируются при редактировании. |
| MLEADER, TABLE | Редактируемые выноски и ячейки таблиц хранятся как собственные объекты. |
| STRETCH, BREAK, ALIGN | Растяжение пересекающей вершиной для прямых линий/полилиний; аналитическое разбиение линий/окружностей/дуг; двухточечное выравнивание в 3D с опциональным масштабированием. |
| XATTACH, XREF | Локальные снимки собственных/DXF-ссылок; явная перезагрузка, выгрузка, загрузка, привязка, отсоединение. Данные файла не загружаются с удалённого URL. |
| UCS | Ортонормированная плоскость черчения; численный ввод с учётом плоскости, привязка и базовые инструменты создания. |
| LAYOUT, PLOT | Постоянные размеры бумаги в миллиметрах, независимые обрезанные видовые окна вида сверху, масштабы и замороженные слои для каждого окна. Физически масштабированный SVG и предварительный просмотр печати в браузере. |

Транзакции содержат производственную метаданные. Невалидная проверка откатывает документ. Циклы определений, отсутствующие ссылки, сингулярные/проективные матрицы, некорректная геометрия, чрезмерная сложность штриховки и невалидные данные таблиц/макетов/стилей отклоняются.

## Исправленные регрессии во время реализации

Исходная обёртка UI отбрасывала аргумент координат экрана для `acceptPoint`. Существующие взаимодействия обрезки/удлинения в браузере его перехватили. Обёртка теперь передаёт этот аргумент, и все 51 исходная проверка браузера снова проходят. Старый псевдоним `DIMLINEAR` больше не направляется на создание выровненного размера.

## Границы обмена

DXF-записчик генерирует настоящие записи BLOCK/BLOCK_RECORD/INSERT и ATTDEF/ATTRIB. Именованные общие блоки и атрибуты для каждого экземпляра сохраняются при полном цикле собственный→DXF→собственный. Неортогональные преобразования блоков не могут быть представлены как обычные преобразования INSERT и при экспорте явно разворачиваются в геометрию.

Острова границ штриховки полилиний сохраняются при DXF-обмене. Поддерживаются линейные и выровненные объекты DIMENSION. Другие вновь созданные режимы размеров, таблицы и выноски экспортируются как отображаемая геометрия, **а не как собственные объекты AutoCAD**. Полный цикл стиля размеров не обеспечивается. Ссылки в DXF становятся обычными блоками; их семантика внешнего вложения доступна только в собственном режиме. UCS, ассоциации и метаданные макета бумаги в этом PR являются только собственными. Не претендуется на беспотерижную конвертацию произвольных DWG/DXF.

Редактирование блоков обновляет геометрию, слои и стили размеров. Определение новых вложенных блоков в активном сеансе редактирования блока не поддерживается. Внешний вид блока группируется на уровне ссылки в текущем рендерере. Графы динамических действий AutoCAD здесь не реализованы.

Макеты печатают вид XY/вид сверху. Они не реализуют общее редактирование CAD в пространстве бумаги, повёрнутые 3D-видовые окна, CTB/STB, метрику SHX или чертежи со скрытыми линиями. Печать в браузере должна использовать 100%/реальный размер без полей; масштабирование через драйвер печати находится за пределами контроля редактора. Предварительный просмотр/редактирование данных макета — через LAYOUT; геометрия модельного пространства остаётся редактируемой в основном окне.

STRETCH не деформирует произвольные тела или частично выбранные коники; BREAK пока не разделяет сплайны. Конструкторская сетка UCS и некоторые наложенные предварительные просмотры всё ещё используют мировые координаты, хотя поддерживаемые результаты инструментов используют выбранную плоскость. Общее решение ограничений и истинные операции B-rep — в следующем PR.

## Проверки для воспроизведения

```sh
python3 -m pip install -r requirements-dev.txt
python3 -m playwright install chromium
# Установите CHROMIUM_PATH на исполняемый файл установленного браузера, если он не находится в /usr/bin/chromium.
python3 tools/verify.py --previews
```

Новые фикстуры независимо читаются и проверяются с помощью ezdxf. Тесты браузера управляют реальными диалогами, командами и загрузками файлов с явной настройкой фикстур. Аппаратное обеспечение WebGPU и фактическое преобразование DWG не покрываются. Ни одно приложение Autodesk или лицензированный кодек не использовались для сертификации результатов.
